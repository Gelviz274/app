# 📱 Activity10

Bienvenido/a a **Activity10**, una aplicación diseñada para ofrecerte una nueva forma de ver el mundo. Esta app contiene tres pantallas iniciales que guían al usuario en su primer contacto con la experiencia:

---

## 🧭 Navegación de pantallas

### 1. **Splash Screen**
- Presentación del logo y el nombre de la app.
- Pantalla de bienvenida breve.
- Autor: *Juan David Gelviz*

### 2. **Main Activity**
- Muestra el nombre de la aplicación y un mensaje introductorio:
  > _"Inicia una nueva aventura con Activity10 y descubre una nueva forma de ver el mundo."_
- Botón principal: **Comienza**
- Enlace adicional para: **Registrarse**

### 3. **Login Activity**
- Ingreso con correo y contraseña.
- Iconos para usuario y clave.
- Botón para ingresar.
- Opción: **Recupera tu contraseña**
- Inicio de sesión con Google.
- Enlace: **¿No tienes cuenta? Regístrate**

---

## 🛠️ Tecnologías sugeridas

- Lenguaje: Kotlin o Java (para Android)
- IDE: Android Studio
- Diseño de UI: XML
- Autenticación sugerida: Firebase Auth (para el login tradicional y Google)
